# そらまもり農地 — 衛星データによる作付確認支援

南相馬市の自治体職員が、営農計画書提出後の作付確認で現地調査すべき農地を絞り込む静的Webアプリです。Sentinel-1 VHの湛水変化とSentinel-2 NDVIの植生ピーク・季節変化を筆単位で説明し、2024年と2025年を比較します。

> [!IMPORTANT]
> 同梱データは、農林水産省2026年筆ポリゴンと2024～2025年のSentinel-1/2実観測を使います。営農申告は照合機能を確認するための参考入力で、24筆・2名の独立目視検証は未実施です。衛星解析は現地確認先の優先順位づけを支援します。

## Webアプリを起動する

Node.js 22以上を使用します。

```powershell
npm install
npm run dev
```

表示された `http://127.0.0.1:5173/` をChromeまたはEdgeで開きます。外部APIやログインは不要です。背景のOpenStreetMapタイルが停止しても、圃場レイヤ、一覧、詳細、候補CSV、試算は利用できます。

## 実装済みの業務フロー

- 公開STACから取得したSentinel-1 RTC 58シーン、Sentinel-2 L2A 111シーンの筆別実観測
- ROI内に中心点がある261筆の状態・面積・確信度・年次変化による絞り込み
- MapLibre地図と圃場一覧・詳細の選択同期
- 2024/2025比較、NDVI/VH時系列、理由コード、観測品質の表示
- 参考申告との一致・不一致・比較不能の表示
- 現地確認候補の追加・削除・`localStorage`保持
- UTF-8 BOM、CRLF、固定23列、数式インジェクション対策済みCSV
- 判定閾値、感度分析、出典、限界の公開
- 360px以上のレスポンシブ表示とキーボード操作

## このゼミの目標と内容

### AFTER — 受講後、こんなことができるようになる

**❶ 生成AIを活用して最新技術の解析を正しく実装できる**
SARも光学も、生成AIで正しい解析コードを書き、基礎原理を理解して手法を再現できる。

**❷ 衛星データ×データサイエンスを検証できる**
AIの出力を鵜呑みにせず、物理法則・センサ特性から解析結果の正しさを見極める力を身につける。

**❸ 解析結果を「届ける」ところまで経験できる**
官公庁・企業・学術——あらゆる現場で通用する提案ストーリーを設計し、非専門家にも伝わる形に落とし込む力を身につける。

### WHAT — ゼミでやること

| カテゴリ | 具体的な内容 |
|---------|-------------|
| データ選定 | 光学・SARの特性を理解し、課題に適したセンサとデータを選ぶ |
| 解析実装 | 生成AIを使って正しい解析コードを書き、衛星データの取得・処理・指標計算までを実装する |
| ファクトチェック | 解析結果を物理法則・センサ特性から検証し、誤りや限界を見極める |
| 提案設計 | 解析をもとに社会課題への提案をチームで作り、非専門家に伝えるストーリーを設計する |

### CHALLENGE — 今回挑む課題「福島の農地」

| 観点 | 内容 |
|------|------|
| 面白さの入口 | 「宇宙から農地を見ると何がわかるか？ AIが出した地図、本当に信用できる？」 |
| 技術的な問い | Sentinel-2のNDVI時系列だけでは雲・季節変動・収穫後の裸地を区別できない。SARを加えると何が解決し、何が解決しないのか。 |
| 社会的な文脈 | 福島浜通りの農地は震災から15年経過した現在も、営農再開と休耕が混在する過渡期。衛星による継続観測は復興の定量的な記録としての価値を持つ。 |

スケジュールの詳細は **`schedule.md`** を参照すること。

### 対象者

- AIの出してきた答えをそのまま信じるだけでは終わりたくない人
- 自分の技術を使って、誰かの意思決定を支える側になりたい人

**リモセン経験者へ:** 光学はもうわかってる。でもSARはあまり理解していない。「光学＋SARの両方を物理の根拠から説明できるようになりたい」人に。

**データ分析／プログラマーへ:** プログラミングに触れたことがある。データから何かを見つけるのが好き。でも衛星データは触ったことがない。「分析のフィールドを広げたい」人に。

### サポート体制

- 質問会・Discordで随時相談
- 光学・SAR知識が混在するチーム編成
- データや解析を事前学習の間に準備・レビュー
- 官公庁・企業・アカデミアの現場を知るメンターからのフィードバック
