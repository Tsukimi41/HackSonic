## リスクと代替案

| リスク | 兆候 | 代替案 |
|--------|------|--------|
| Phase 0 が合宿前に終わらない | 9/7 時点で `field_features.csv` が無い | Day1 夜90分を Phase 0 に充て、Day2 午前まで延長。拡大は Day2 15:00 まで判断しない |
| Day2 に判別マップが出ない | 15:00 の中間レビュー時点で未出力 | Minimum を切り下げる（相馬市・2024単年・田のみで確定させる） |
| GEE がタイムアウトする | 8,581 筆で `getInfo()` が返らない | `N_LIMIT` を戻して分割実行し、CSV を結合する |
| 一次検証の照合先が決まらない（#1） | Day1 で決着しない | 一次検証を落とし、二次検証（対照地・松川浦）と三次検証に絞る。限界として明記 |
| メンバー間で環境差が出る | 同じコードで違う結果 | Colab に統一（ローカル Python を使わない）。`config.py` の Version を固定 |
