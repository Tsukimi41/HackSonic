## ① 「データと背景知識」の整理結果

### 1-1. 対象エリアと現象

対象は福島県浜通りの相馬市・南相馬市の農地。震災から15年を経て、営農再開と休耕が併存している。

現象を1行で:
> **農地の「植生の濃さ」と「表面の平滑さ」が季節ごとに変わるから、作付と休耕が区別できる。**

作付水田は5月に水を張って鏡面反射で極端に暗くなり、6〜8月に葉が茂ってNDVIが上がりSARも体積散乱で明るくなる。休耕地はこの往復をしない。

判別に使う観測時期は **5月（湛水期）と8月（最盛期）の2時期**。5月は水張りによる σ⁰ の急落が作付の強い証拠になり、8月はNDVIのピークで生育を確認できる。片方だけでは収穫後の裸地と休耕地を区別できない。

### 1-2. 季節サイクル

| 時期 | 農地の様子 | 光学（NDVI） | SAR（σ⁰ VH） |
|------|-----------|-------------|--------------|
| 4月 | 代かき前・休耕中 | 低い（裸土） | 中（土の表面散乱） |
| 5月 | 湛水期（水張り） | 低い（水面） | **暗い（鏡面反射）** |
| 6〜7月 | 生育期 | 上昇 | 高（葉の構造散乱） |
| 8月 | 最盛期・収穫前 | ピーク付近 | 高（体積散乱） |
| 収穫後 | 裸土・稲わら | 低下 | 低下 |

### 1-3. センサ仕様

**光学（Sentinel-2）**

NDVI = **(B8 − B4) / (B8 + B4)**（B8 = NIR 約842nm、B4 = Red 約665nm）

- B5 を NIR に使うと: **NDVIが過小評価される。** B5(705nm)はレッドエッジの立ち上がり途中で、葉の海綿状組織による強い構造反射をまだ捉えていないため、分子 (NIR − Red) が小さくなる
- CRS を揃えないと: **ピクセルと外部ポリゴンの境界がずれ、圃場の縁で別の土地の値が混ざる（ミクセル）。** Sentinel-2 は EPSG:32654（UTM 54N）、筆ポリゴンは JGD2011 系なので再投影が必要
- 雲量フィルタ: `CLOUDY_PIXEL_PERCENTAGE < 20`

**SAR（Sentinel-1）**

- VV と VH の違い: VV は送信・受信が同じ垂直偏波で地表面や垂直な茎の散乱に強く反応する。VH は偏波が異なり、**葉や枝で電波の向きが変わる体積散乱**を捉えるため作物の繁茂状況の判別に向く
- `10*log10()` をしてはいけない理由: **`COPERNICUS/S1_GRD` は既に dB（σ⁰）で値が負だから。** 負数の log10 は定義域外で GEE がマスクする
- 昇交・降交を揃えないと: **入射角が観測ごとに変わるため σ⁰ が揺れ、地表が変化していなくても値が動く。** 湛水と乾燥を誤読する
- スペックル対策: **期間内の median**（平均は明るい外れ値に引っ張られる）。加えて筆ポリゴンによる圃場単位の空間平均

### 2-2. 修正前後の差分（AI利用時の記録）

**光学**
```javascript
// 修正前
img.normalizedDifference(['B5', 'B4'])
// 修正後
img.normalizedDifference(['B8', 'B4'])
```
理由: NDVI の NIR は B8。B5 はレッドエッジの立ち上がり途中で葉の構造反射を捉えないため NDVI が過小に出る。

**SAR**
```javascript
// 修正前
var s1_vh_mean = s1.select('VH').mean().clip(roi);
var fallow_mask = ndvi_max.lt(0.35).and(s1_vh_mean.log10().multiply(10).lt(-20));
// 修正後
var s1_vh_med = s1.select('VH').median().clip(roi);
var fallow_mask = ndvi_max.lt(0.40).and(s1_vh_med.lt(-15.0));
```
理由: `S1_GRD` は既に dB。負数の log10 がマスクを生み判定が死ぬ。median はスペックル（外れ値として乗る）に対して平均より頑健。

### 2-3. 修正しても残った欠陥（罠①〜③に含まれないもの）

罠3つを全部直しても、判定結果は使えなかった。ESA WorldCover（独立した土地被覆図）と交差集計した結果:

| クラス | 土地被覆 | 割合 |
|---|---|---|
| 80 | **水域** | **58.1%** |
| 50 | **市街地** | **17.6%** |
| 40 | **農地** | **8.5%** |
| 30 / 60 / 10 / 90 | 草地・裸地・樹林・湿地 | 15.8% |

**農地は8.5%のみ。非農地が91.5%。** クラス別の検出率は水域88.4%、裸地66.0%、市街地18.3%に対し、樹林は0.37%。両極が揃っていることから、**条件式そのものは物理的に正しく働いており、問題は適用範囲だけ**と判断できる。

物理的な理由: 水面と平滑な舗装面・屋根は鏡面反射で電波を衛星に返さないため、VHが暗くなる。低NDVIと組み合わさると休耕農地と区別できない。SARで建物が明るく見えるのは壁と地面が作る角のダブルバウンスであって、平らな面は水面と同程度に暗い。

**結論: 筆ポリゴンによる範囲限定が必須。** 農地に限定すると休耕疑いは約338 ha、限定しないと約4,039 ha で**約12倍の差**。前処理の1つの選択で自治体に報告する数字の桁が変わる。

### 2-4. 自分が犯した単位の誤り

「5,119件 = 5,119 ha = 51.2 km²」と換算したが誤り。`reduceRegion` の `scale:100` が EPSG:4326 で解釈され、緯度37.7°では経度方向が縮む（1/cos(37.7°)≒1.26）。実際は**1件あたり約0.79 ha**で、正しくは約4,039 ha（40 km²）、ROI比9.7%。

**AIの出力を疑う対象には、自分自身の出力も含まれる**という実例になった。

### 2-5. 変動要因の切り分け

当初「前処理変更で約3 dB動いた」と読んだが、同一座標で測り直すと前処理の効果は約1 dBだった。3 dBは場所の違い（約200m）によるものだった。

| 要因 | 変動量 |
|---|---|
| 前処理（mean → median・期間拡大） | 約 1 dB |
| **200m 離れた地点間の空間ばらつき** | **約 3 dB** |
| 数km離れた3地点間のばらつき | 約 6 dB |

**空間ばらつきが前処理の影響の約3倍大きい。** 閾値 -15 dB に対して隣接ピクセルが3 dB揺れるため、ピクセル単位の判定は原理的に安定しない。圃場単位の空間集計（Zonal Statistics）が必要で、これが筆ポリゴンを使う2つめの理由になる。
