## 1. 取り組みの概要

福島県浜通り、特に相馬市・南相馬市の農地を対象に、Google Earth Engine（GEE）と Sentinel-1／Sentinel-2 を使った衛星データ解析を学習・実行した。光学画像の NDVI、SAR の VV／VH 後方散乱、農地区画ごとの時系列特徴を組み合わせ、主に水稲の作付・休耕候補を判別する方法を検討した。

活動は、次の順で進めた。

1. 教材・演習ファイルをローカル環境に取り込んだ。
2. Week 1 で Sentinel-2 と NDVI の基礎を学んだ。
3. Week 2 で Sentinel-1 SAR、偏波、散乱機構を学んだ。
4. Week 3 相当として、閾値ルール、機械学習、クラスタリング、異常検知、精度評価を試した。
5. チーム成果物を読み、team-alpha・beta・gamma の判定方法を比較した。

## 3. Week 1：光学衛星・Sentinel-2・NDVI

`exercises/week1_exercise.ipynb` と `submissions/individual/matsui/week1/exercise.md` を中心に、以下を実施した。

- GEE の `COPERNICUS/S2_SR_HARMONIZED` から Sentinel-2 L2A 画像を取得した。
- 日付、解析範囲、雲量で ImageCollection を絞り込む方法を確認した。
- 表示範囲には `DISPLAY_ROI` を使い、処理対象と表示対象の範囲を意識した。
- True Color 表示では `B4`（赤）、`B3`（緑）、`B2`（青）を使い、表示上限を `2000` に設定した。
- `normalizedDifference(['B8', 'B4'])` により NDVI を計算した。
- 森林、水域、裸地、都市、農地のスペクトルプロファイルを比較した。
- 7月の生育期は NDVI が高く、10月の収穫後は低下するという季節変化を考察した。
- 収穫後の農地と休耕地は、どちらも植生が少なく見えるため、単一時点の光学画像や NDVI だけでは区別しにくいことを整理した。
- 区別には、年間の時系列変化や SAR など、別の情報を組み合わせる必要があると理解した。

Week 1 の提出ログには、取得画像数21枚、選択画像 `20250607T011649_20250607T011651_T54SVG`、撮影日2025年6月7日という実行結果が記録されている。ただし、NDVIの実測値を記入する箇所には `〇〇` が残っている。

## 4. Week 2：Sentinel-1 SAR と散乱機構

`exercises/week2_exercise.ipynb` と関連するチュートリアルを使い、以下を学習・実行した。

- Sentinel-1 GRD の IW モードから VV／VH 偏波を取得した。
- SAR画像の明るさが後方散乱係数 σ⁰［dB］を表すことを確認した。
- 表面散乱、体積散乱、ダブルバウンス散乱の3つを、画像中の水域・森林・都市と結び付けて考察した。
- 水域や湛水した水田は、滑らかな水面で鏡面反射が起こり、電波がセンサへ戻りにくいため VV／VH とも暗くなると理解した。
- 都市部は建物壁面と地面によるダブルバウンスのため、特に VV で明るくなりやすいと理解した。
- VH は枝、葉、茎などの複雑な構造による体積散乱を捉えやすく、植生がざらついた明るさとして見えることを確認した。
- 同時期の Sentinel-2 RGB と SAR を並べ、光学では色、SARでは水面・粗さ・立体構造の違いを見ていることを比較した。
- 光学画像では雲の下が見えない一方、SARは雲の影響を受けにくく地表を観測できることを整理した。

実行中には、光学RGBが黒く表示される問題を調べた。画像検索を `ROI`、切り出しを `DISPLAY_ROI` としていた範囲のずれを疑い、検索側も `DISPLAY_ROI` に統一した。また、RGBのバンドを `['B4', 'B3', 'B2']`、表示スケールを `2000` とした。VVとVHでは値域が異なるため、それぞれ別に表示範囲を計算する必要があることも確認した。

## 5. Week 3：作付・休耕判別と機械学習

`tutorials/03_machine_learning.ipynb` を中心に、Python初心者としてコードの意味を一つずつ確認しながら実行した。

### 5.1 Python／Notebookの仕組み

- `from env import gee_setup, setup_font` により、同じ `tutorials/` にある `env.py` の関数をNotebookから読み込んでいることを理解した。
- Pythonがモジュールを探す場所、Notebookの実行ディレクトリ、Colabで `env.py` を使う場合の違いを確認した。
- 解析期間、対象年、CRS、解像度、雲量、Sentinel-1の軌道方向・観測モードなどを、再現性のため冒頭の設定セルにまとめる意味を学んだ。

### 5.2 試した判定手法

- 物理ルールによる疑似ラベル作成
  - 5月の `VH` が低いことを湛水の手掛かりにする。
  - 8月や夏季の `NDVI` を生育の手掛かりにする。
  - どちらの条件にも当てはまらないものは未判定とする。
- RandomForestによる教師あり分類
- KMeansによる教師なしクラスタリング
- IsolationForestによる異常検知
- NDVI・VH・VVの単一時点の値だけでなく、年間最大値、振幅、ピーク月、生育勾配など「時系列波形の形」を使う特徴量設計
- `predict_proba` を使った確信度と、要現地確認となるグレーゾーンの考え方
- ピクセル単位ではなく、一筆（農地区画）内を集計する Zonal Statistics によるノイズ低減

この検討を通じ、単純な閾値や機械学習以外にも、農作業・生育・収穫に対応する時系列の変化、周期性、物理・生態モデルとの照合、区画形状、SAR干渉コヒーレンスなどを利用する発想があることを調べた。

### 5.3 精度評価で得た結果

`validation_labels.csv` を使った目視検証では、16件（休耕10件、作付6件）に対して次の結果を得た。

```text
混同行列（行=真、列=予測）
[[8, 2],
 [0, 6]]

F1        = 0.857
Precision = 0.750
Recall    = 1.000
IoU       = 0.750
```

この結果では、作付6件をすべて検出した一方、休耕2件を作付と誤判定した。したがって「作付の見逃しはなかったが、不要な現地確認を増やす偽陽性があった」と解釈した。

ただし、学習外の圃場が7件しかなく、評価に学習データを含めたため、数値は楽観的な参考値である。物理ルールは未判定が多く、同じ検証セットでは F1 等が0となった。通常のRandomForestと派生特徴量を加えたRandomForestは、この小さな検証セットでは同じ結果だった。

### 5.4 評価対象についての重要な整理

現在のルールは、5月の湛水と夏の高NDVIを使っている。このため、厳密な「農地／非農地」分類というより、実質的には「水稲作付らしい／水稲作付ではなさそう」という判定に近い。

畑、果樹園、牧草地は農地であっても5月に湛水しないため、作付側に入りにくい。また、休耕側には裸地、市街地、道路、水域などが混ざる可能性がある。農地／非農地を判定したい場合は、筆ポリゴンや土地利用データなどで農地マスクを作り、目的に対応した正解ラベルを別途用意する必要がある。

### 5.5 閾値感度分析で行った試行錯誤

- VH、作付側NDVI、休耕側NDVIの候補を広く振り、「粗く探索してから変化の大きい範囲を細かく見る」方法を試した。
- 休耕数は主に `NDVI_low_th` で決まるため、VH閾値を変えた線が重なって見えることを理解した。
- `NDVI_th` を `NDVI_high_th`／`NDVI_low_th` に分けた後、古い列名を参照して `KeyError` が発生し、列名の整合を確認した。
- 3つの閾値を同時に動かした結果を2次元の `pivot` にしようとして、重複キーによる `ValueError: Index contains duplicate entries` が発生した。
- 2次元グラフにする際は、3変数のうち1つを固定する必要があると理解した。

## 6. 一筆解析パイプラインの理解

`tutorials/04_field_pipeline.ipynb` では、次の流れを確認した。

1. GEEで Sentinel-1／2 を取得・前処理する。
2. `reduceRegions` により、農地区画ごとの月別 NDVI／VV／VH 平均を計算する。
3. Python側で月別時系列を整形する。
4. 年間最大値、振幅、ピーク月、生育勾配などの波形特徴量を計算する。
5. 「1筆×1年＝1行」の特徴量表を作る。
6. 判定結果や確信度を使い、自治体職員の現地巡回の優先順位付けにつなげる。

ここでは、ピクセル1点の値よりも、一筆単位に集計した時系列の形を見る方が、SARのスペックルや観測値の揺らぎに強いことを学んだ。

## 7. チーム成果物から調べたこと

team-alpha、team-beta、team-gamma の成果物を読み、判定方法を比較した。

- team-alpha
  - 相馬市・南相馬市の田を筆単位で解析する。
  - 4月の乾田状態を基準に、5月以降のSAR低下で湛水を検出し、NDVIで生育を確認する。
  - 本体は機械学習ではなく、物理仮説に基づく時系列ルールである。
- team-beta
  - 初期はVHとNDVIの閾値、後半はNDVI・VV・VHの年間振幅を使う。
  - 森林との分離やグレーゾーンを重視している。
  - 基本はルールベースで、機械学習は使用していない。
- team-gamma
  - SARのベースラインからの低下と、光学のMNDWI上昇を組み合わせた湛水イベント検出を行う。
  - SARと光学の両方で検出できた場合を高信頼とし、片方のみの場合を要確認とする。
  - こちらも機械学習ではなくルールベースである。

この比較から、説明可能性を重視する場合は、機械学習の確率だけでなく、湛水・生育・振幅など物理的に説明できる根拠を示すことが重要だと理解した。
