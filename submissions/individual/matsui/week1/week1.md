## 取り組んだ内容

Week 1では、Google Earth Engine（GEE）を使い、Sentinel-2の光学衛星画像を取得・表示して、NDVIと地物ごとの分光特性を学んだ。

### 1. 実行環境とGEEの準備

- VS Codeのローカル環境からPython仮想環境を使用した。
- `earthengine-api` と `geemap` を読み込み、GEEプロジェクト `astro-camp-matsui` で初期化した。
- 解析範囲を `ROI`、画像表示用の小さな範囲を `DISPLAY_ROI` として設定した。

### 2. Sentinel-2画像の検索

`COPERNICUS/S2_SR_HARMONIZED` から、次の条件で画像を検索した。

- 観測期間
- 対象範囲
- `CLOUDY_PIXEL_PERCENTAGE` による雲量

条件を変えながら複数回試した。Notebookに保存されている実行結果の一例では、2023年10月を対象として2枚が見つかり、2023年10月14日の画像を選択した。提出ログには、別条件で21枚を検索し、2025年6月7日の画像を選択した記録も残した。

### 3. True Color画像の表示

Sentinel-2の次のバンドをRGBに割り当て、自然色画像を表示した。

```python
vis_rgb = {
    'bands': ['B4', 'B3', 'B2'],
    'min': 0,
    'max': 2000
}
```

- `B4`: 赤
- `B3`: 緑
- `B2`: 青

反射率データは整数値で格納されているため、表示時には0〜2000の範囲を0〜1にスケーリングした。

### 4. NDVIの計算と表示

近赤外バンド `B8` と赤バンド `B4` を使い、次のコードでNDVIを計算した。

```python
ndvi = image.normalizedDifference(['B8', 'B4']).rename('NDVI')
```

保存されている実行結果では、NDVIの範囲は次のようになった。

```text
最小値: -0.716
最大値:  0.944
```

NDVI画像とヒストグラムを表示し、植生が多い場所ほど値が高く、水域などでは低くなることを確認した。

### 5. 地物ごとのスペクトルプロファイル

森林、水域、裸地、都市、農地の代表点を設定し、各バンドの反射率を比較した。赤バンドと近赤外バンドの例は次の通りだった。

| 地物 | B4（Red） | B8（NIR） | 観察 |
|---|---:|---:|---|
| 森林 | 0.070 | 0.201 | 近赤外の反射が赤より高い |
| 水域 | 0.029 | 0.005 | 全体的に反射が低い |
| 裸地 | 0.122 | 0.265 | 植生とは異なる緩やかな反射 |
| 都市 | 0.156 | 0.177 | 赤と近赤外の差が小さい |
| 農地 | 0.059 | 0.297 | 近赤外反射が高く、植生の特徴が出た |

農地や森林では、植物が赤色光を吸収し、近赤外を強く反射するため、B8がB4より高くなることを確認した。

### 6. 雲の影響の確認

雲量80%以上の画像をあえて検索し、雲が光学画像とNDVIへ与える影響を確認した。

```text
該当画像数: 6枚
選択画像: 20240602T011659_20240602T011653_T54SVG
雲被覆率: 87.84821%
```

光学画像では雲によって地表が隠れ、NDVIも正しく読み取れなくなる場所があることを確認した。

## 考察

生育期の農地では植物の葉が増えるためNDVIが高くなり、収穫後は植物体が減ってNDVIが低下する。したがって、複数時期のNDVIを比較すれば、植生の季節変化を捉えられる。

一方、収穫後の農地と休耕地は、どちらも植生が少なく土壌などが見えるため、単一時点の光学画像やNDVIだけでは区別しにくい。作付の有無を判定するには、年間のNDVI時系列や、雲の影響を受けにくいSARの情報を組み合わせる必要がある。

## 学んだこと

- GEEで衛星画像を日付・範囲・雲量から検索する方法
- Sentinel-2のTrue Colorバンドの組み合わせ
- NDVIの計算方法と値の読み方
- 地物によるスペクトル反射の違い
- 光学衛星画像が雲の影響を受けるという限界
- 1時点だけでなく時系列で観測する必要性
