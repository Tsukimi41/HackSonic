### Q1. 7月と10月のNDVI値はどう変わるか？

7月は水稲の生育期にあたるため、農地では葉が増えて光合成が活発になり、NDVIが高くなると考えられる。実際にNDVIマップでも、作付け中の農地や森林は緑色が強く表示され、植生が多い場所として確認できた。

一方、10月は収穫後に近い時期で、田んぼの植物体が少なくなり、地表面の土壌や刈り跡の影響が大きくなる。そのため、7月に比べてNDVIは低下すると考えられる。

今回の結果では、7月のNDVIはおよそ**〇〇**、10月のNDVIはおよそ**〇〇**となり、生育期から収穫後にかけて植生量が減少する傾向が確認できた。

### Q2. 収穫後の農地と休耕地を光学だけで区別しようとすると、なぜ失敗するのか？

光学センサは、地表面が太陽光をどの波長でどれだけ反射するかを観測している。収穫後の農地では、緑の葉が少なくなり、土壌や乾いた植物残渣が主に見える。休耕地も植生が少ない場合には、同じように土壌や低い草が見えるため、可視光や近赤外の反射特性が似やすい。

その結果、NDVIだけを見ると、収穫後の農地も休耕地も「植生が少ない場所」として同じような低い値になることがある。

つまり、光学センサだけでは、そこが「今年作付けされて収穫後なのか」、それとも「そもそも休耕していたのか」という時間的な履歴までは直接わからない。この区別には、年間の時系列変化やSARなど別の情報を組み合わせる必要がある。

### Sentinel-2 L2A コレクションの取得

Sentinel-2 L2A コレクションの取得では、以下のように指定した。

```python
collection = (
    ee.ImageCollection('COPERNICUS/S2_SR_HARMONIZED')
    .filterDate('2024-04-01', '2024-09-30')
    .filterBounds(DISPLAY_ROI)
    .filterMetadata('CLOUDY_PIXEL_PERCENTAGE', 'less_than', 20)
)
```

期間は、水稲の作付けから生育・収穫前までを含むように**4月から9月**にした。

場所は、表示対象の小さな領域である `DISPLAY_ROI` で絞り込んだ。

雲量は `CLOUDY_PIXEL_PERCENTAGE` が**20%未満**の画像に限定し、雲の少ない比較的見やすい画像を選ぶようにした。

実行結果では、該当画像数は**21枚**で、選択された画像は


撮影日は **2025-06-07** だった。

この時期は田植え後から分げつ期に向かう時期で、水稲の植生が増え始める段階だと考えられる。

### RGB表示

RGB表示では、Sentinel-2のバンドを以下のように指定した。

```python
vis_rgb = {
    'bands': ['B4', 'B3', 'B2'],
    'min': 0,
    'max': 2000
}
```

* `B4`：赤（Red）
* `B3`：緑（Green）
* `B2`：青（Blue）

B4が赤、B3が緑、B2が青なので、**True Color画像**として表示するにはこの順番にする必要がある。

また、Sentinel-2の反射率は10000倍された整数値で格納されているが、表示では暗くなりすぎないように `vis_rgb['max'] = 2000` として表示範囲を設定した。
