# 候補エリア選定ドキュメント：相馬市・南相馬市

## 1. 目的と位置づけ

相馬市・南相馬市の**作付／休耕判別解析**（Sentinel-2 / Sentinel-1 時系列）の対象エリアと、解析の参考に用いる地理参照点（水・森林・農地）を定義する。

- 座標系はすべて WGS84（EPSG:4326）。
- GEE の `ee.Geometry.Rectangle` は `[lonMin, latMin, lonMax, latMax]` の順。
- 参照点は「農地の作付状況を判読する際の背景・文脈」として使う。水場・森林は OpenStreetMap（Overpass API）から取得し、**Sentinel-2 画像で最終確認する**。

## 2. 選定基準

- 農地（圃場）が面的にまとまっていること。
- 水場（河川・ため池・潟湖）と森林（海岸林・丘陵林）が近傍にあり、判読の背景として使えること。
- 東側の海岸平野を対象とし、西側の阿武隈高地（山林主体）は対象外とする。
- 作付の季節変化（2024年7–9月）を Sentinel-2 で確認できること。

## 5. 水場・森林の座標の取得方法

### 5.1 推奨ワークフロー

1. **OpenStreetMap（Overpass API）** — 今回実施。地域の名前付き河川・ため池・樹林を座標付きで取得できる。無料・ログイン不要。
   - 再現用スクリプト: `resources/osm_coordinate.py`（結果CSV: `resources/osm_coordinates_results.csv`）
2. **GEE + 土地被覆データ（JAXA ALOS 高解像度土地利用 / ESA WorldCover）** — 全域を一貫した条件で分類。農地・水・森林のマスク作成に使う。
3. **Sentinel-2 真彩色・NDWI（水）／NDVI（緑）** — 2024年7–9月シーンで水場・森林の存在を目視・指標で最終確認。
4. **国土数値情報（土地利用3次メッシュ）・環境省植生図** — 公的データで土地利用を補完。
5. **eMAFF 農地ナビ（map.maff.go.jp）** — 農地筆ポリゴンの確認（作付対象の特定）。

### 5.2 Overpass クエリ（再現用の要点）

- 水場: `nwr["natural"="water"]` ＋ `nwr["waterway"="river"]`（ため池は `water=reservoir` タグ）
- 森林: `nwr["natural"="wood"]` ＋ `nwr["landuse"="forest"]`
- 注意: `waterway=stream`（水路）は大量に混入するため除外して集計（本スクリプトでは別カテゴリ化）。

### 5.3 注意事項（OSMの限界）

- OSM の `water=river` タグ付きポリゴンの一部は**水田湛水（季節的水面）**を表す場合があり、通年水面とは限らない。Sentinel-2 で確認すること。
- 南相馬市の新田川・渋佐川河口の座標は OSM の概算値。確定には GEE の `ee.Geometry.Point` 表示または流域地図との照合が必要。
