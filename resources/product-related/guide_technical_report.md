# 技術レポートの書き方ガイド — Markdown 形式

> このガイドは、合宿の**技術レポート（Markdown）**の構成と書き方を説明します。
> 技術レポートは**衛星データの知識がある専門家・メンターが読む**ものです。物理的根拠・不確実性・再現性を正確に記述してください。
> **提出は合宿後1週間以内（9/19 金 を目安）**、`submissions/camp/team-*/technical_report.md` です。
>
> **合宿中（9/8〜9/12）は、最終日に使う自治体向けスライドに集中してください。**
> 合宿中にレポートを書き上げる必要はありません。合宿中にやるのは
> 「あとで書けるように材料を残すこと」だけです。

---

## 1. 技術レポートの目的と読者

| 項目 | 内容 |
|------|------|
| 読者 | メンター・技術レビュアー（リモートセンシングの専門知識あり） |
| 目的 | 解析の設計・実装・検証プロセスを追跡可能な形で記録する |
| 評価される点 | 物理的根拠・不確実性の正直な記述・再現性・AIの活用と検証の記録 |
| 分量の目安 | A4換算で 5〜10ページ程度（Markdown） |

### 合宿中は「材料を残す」だけ、執筆は合宿後

A4換算 5〜10ページを合宿中に書こうとすると、スライドが犠牲になります。
**合宿中は各日の終わりに5分だけ使って、下の「残すもの」をメモに書き出してください。**
それさえあれば、合宿後にレポートは書けます。

| いつ | 合宿中に残すもの（メモで可） | 後でどのセクションになるか |
|------|------------------------|--------------------|
| **合宿前** | 解析計画書（`exercises/analysis_doc.md`）Step1・Step2 | §1 課題と目的・§2 物理仮説（ほぼ転記できる） |
| **Day 2** | 使ったデータの期間・CRS・雲や軌道の条件（＝再現性ヘッダの中身） | §3 データと前処理 |
| **Day 3** | 採用した閾値**とその理由**・混同行列の数字・レビューで受けた指摘 | §4 解析手法・§5 検証結果 |
| **Day 4** | ファクトチェック3層の結果・詰まった点・費用対効果の数字 | §6 考察と限界・§7 社会実装 |
| **合宿後（〜9/19）** | 上のメモを本文に起こす | 全セクション＋§0・§8・§9 |

> **合宿中にメモを残さないと、合宿後に「なぜその閾値にしたのか」を思い出せません。**
> 数字そのものより、**「なぜそう決めたか」**を1行ずつ残すことが重要です。

自治体向けスライドとの違いを常に意識してください：

| | 技術レポート | 自治体向けスライド |
|--|------------|----------------|
| 読者 | 専門家（衛星の知識あり） | 非専門家（農政の知識あり） |
| 重視すること | 物理的根拠・不確実性・再現性 | 結論・コスト・次のアクション |
| 技術用語 | 使う（定義は省略可） | 使わない（必ず平易な言葉に換える） |
| 誤差の書き方 | 数値と原因を詳細に | 「約X%は要確認」の1行で |

```markdown
## 1. 課題と目的

### 1.1 対象課題

相馬市・南相馬市の農地（約◯◯ha）において、Sentinel-1（SAR）と
Sentinel-2（光学）を用いて作付地と休耕地を判別し、農地台帳の
更新業務の効率化を支援することを目的とする。

### 1.2 この解析を行う理由

東日本大震災後の営農再開状況は圃場ごとに異なり、現状把握には

確認が必要なエリアを絞り込むことができれば、コストを削減しつつ
継続的なモニタリングが可能になる。
```

### 2. 物理仮説

**「なぜ光学とSARで作付/休耕が判別できるか」を、季節イベントと観測量のペアで記述します。** ここが技術レポートの核心です。

```markdown
## 2. 物理仮説

水田の作付地と休耕地は、以下の季節イベントによって光学・SAR の
観測量に特徴的なパターンを示す。

| 季節イベント | 時期 | 観測量の変化 | 物理的根拠 |
|------------|------|------------|----------|
| 水張り（湛水） | 5月上旬 | σ⁰(VH) が急激に低下（-18 dB 以下） | 水面からの鏡面散乱により後方散乱が減少 |
| 稲の繁茂 | 7〜8月 | NDVI が 0.7 以上に上昇 | 葉のクロロフィルと葉肉構造による近赤外反射 |
| 収穫・裸地 | 9〜10月 | NDVI 低下・σ⁰ 増加 | 植被の除去により裸地散乱に移行 |

休耕地では5月の湛水が行われないため σ⁰(VH) の急落が見られず、
生育期（7〜8月）も NDVI がピークに達しないことで判別する。
```

**よくある不足点**：「NDVIとVHを使いました」だけでは不十分です。「なぜそのバンド・偏波が、この季節のこの現象を検出できるか」を散乱機構やスペクトル特性から説明してください。

### 3. データと前処理

解析計画書 §2「AIへの5つの問い」を満たす形で、具体的な数値・条件を記述します。

```markdown
## 3. データと前処理

### 3.1 使用データ

| データ | 取得元（GEE ID） | 期間 | 解像度 |
|-------|--------------|------|-------|
| Sentinel-2 L2A | COPERNICUS/S2_SR_HARMONIZED | 2021-01〜2025-12（うち3〜10月） | 10 m |
| Sentinel-1 GRD | COPERNICUS/S1_GRD | 2021-01〜2025-12（うち3〜10月） | 10 m |
| 農地筆ポリゴン | 農水省 農地筆ポリゴンデータ | 2024年版 | — |

**取得期間と解析対象年は分けて書く。** `field_features.csv` は1筆×1年で1行のため、
取得期間は複数年（2021〜2025）であり、判別・精度評価に使う「解析対象年」はそのうち1年（本レポートでは2024年）である。

### 3.2 前処理の詳細

**① 単位**
- Sentinel-1 GRD は既に dB スケールで提供されている（線形値への変換は行わない）
- Sentinel-2 は表面反射率（0〜1）で使用

**② バンド・偏波**
- NDVI: (B8 - B4) / (B8 + B4)（B8 = NIR, B4 = Red）
- SAR: VH 偏波を主特徴量として使用（VV は補助的に使用）

**③ 座標系（CRS）・集計スケール**
- 解析全体を EPSG:32654（WGS84 / UTM zone 54N）に統一
- 農地ポリゴンは JGD2011（EPSG:6668）から変換
- 空間集計（`reduceRegions`）は scale = 10 m（Sentinel-1/2 の native 解像度）

**④ 軌道方向・観測モード**
- 降交軌道（Descending）に統一（`orbitProperties_pass == 'DESCENDING'`）
- 昇交データとの混在なし
- **この軌道を選んだ理由**：対象エリアでは 2022〜2024 年に昇交軌道の観測が存在せず、
  降交軌道のみが通年で揃うため（Sentinel-1B 停止の影響）
- 観測モードは IW、偏波は VV / VH

**⑤ 観測時期・雲量**
- Sentinel-2：雲量 20% 以下のシーンのみ使用（`CLOUDY_PIXEL_PERCENTAGE < 20`）
- 3月〜10月を月別平均として集計し、5月（湛水）・8月（繁茂）を判別の基準月として使用
```

### 4. 解析手法

選択した手法とその理由、期待する出力を記述します。

```markdown
## 4. 解析手法

### 4.1 手法の選択と理由

検討した手法候補：
- 時系列ルールベース（閾値法）
- 特徴量スタック + 機械学習（Random Forest 等）
- 変化検出（差分・比）

採用した手法：時系列ルールベース + 疑似ラベルによる特徴量スタック

理由：
1. 正解ラベルが存在しないため、物理的根拠のある閾値を先に定義することが
   モデルの解釈性・説明可能性において有利である
2. ML のみの手法では「なぜそう判定したか」を自治体に説明できない
3. 疑似ラベルを ML に学習させる場合も、物理ルールで定義した疑似ラベルを
   用いることで根拠を明確にできる

### 4.2 特徴量

列名は `field_features.csv` のものをそのまま使う（**すべて小文字**）。

| 特徴量 | 計算方法 | 物理的意味 |
|-------|---------|-----------|
| `ndvi_max` | 3〜10月の最大NDVI | 繁茂期の最大植生量 |
| `ndvi_amplitude` | `ndvi_max` − `ndvi_min` | 生育の振幅（作付で大きい） |
| `ndvi_max_month` | NDVIが最大となる月 | 生育ピークの時期 |
| `ndvi_aug` | 8月の平均NDVI | 出穂期の植生活性 |
| `growth_slope` | （`ndvi_max` − `ndvi_may`）/（ピーク月 − 5） | 生育の立ち上がり勾配 |
| `vh_may` | 5月のσ⁰(VH)の圃場平均（dB） | 湛水の有無 |
| `vh_min` | 年間最小のσ⁰(VH)（dB） | 湛水期の急落 |
| `vh_amplitude` | VHの最大値 − 最小値（dB） | 季節変化の振幅 |
| `vh_temporal_diff` | `vh_aug` − `vh_may`（dB） | 5月→8月の変化（作付で正に大きい） |
| `vv_vh_may` / `vv_vh_aug` | `VV_db` − `VH_db`（dB） | 偏波比。**dB では比は「差」**。割り算は不可 |

### 4.3 疑似ラベルの定義

（チームで定義した疑似ラベルの条件を記述する）
```

### 6. 考察と限界（最重要）

「不確実性を正直に言語化する」ことが最も評価されるセクションです。

```markdown
## 6. 考察と限界

### 6.1 結果の解釈

（解析結果が物理仮説と整合しているか。意外な結果があればその考察を書く）

### 6.2 解析の限界

本解析には以下の制約があることに注意が必要である。

**① 疑似ラベルの不確実性**
精度評価は疑似ラベル（ルールベース定義）との一致度であり、真の休耕地ラベルとの
比較は行っていない。実際の精度は本レポートの数値より低下する可能性がある。

**② 雲の影響**
◯月は雲量が多く、有効な Sentinel-2 シーンが限られた。この時期のデータ欠損が
時系列解析に影響している可能性がある。SAR（Sentinel-1）はこの制約を受けない。

**③ ミクセル問題**
圃場面積が小さいエリアでは、10m解像度でも境界ピクセルに隣接地（水路・道路）
の影響が混入する。（特に面積◯◯㎡以下の圃場）

**④ 観測頻度の制約**
Sentinel の再訪周期は約6日（同一軌道方向では12日以上）であり、短期的な
農地状態の変化を捉えられない場合がある。
```

**よくある不足点**：「精度が低かった」だけでは不十分です。「なぜ低かったか（センサの制約・観測条件・疑似ラベルの定義・空間的な問題）」を物理的根拠から説明してください。
